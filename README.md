# 萤火·指尖星光 · 公开资料

本仓库只存放「萤火·指尖星光」的公开隐私政策与支持说明静态页，不包含 App 源码、素材或签名文件。App 在手机上显示的名称为「萤火」，开发者为刘宝志 / Liu Baozhi。

## 文件

- [index.html](index.html)：首页，介绍产品及公开资料入口。
- [privacy.html](privacy.html)：隐私政策，说明设备本地处理、权限、系统备份及网站托管。
- [support.html](support.html)：支持说明，包含设置入口、退出方式、权限及数据清理说明。
- [styles.css](styles.css)：三页共用的本地样式表。
- `.nojekyll`：空文件，供将来使用 GitHub Pages 时使用。
- `README.md`：本仓库说明。

页面以简体中文编写，使用原生 HTML 与 CSS，无 JavaScript、表单、第三方库或外部资源依赖。所有内部链接及样式表引用均使用相对路径，可适配将来位于子路径的项目站。

## 本地查看与托管状态

可直接打开 `index.html` 查看，并通过页眉导航切换页面；无需安装依赖或构建。

**GitHub Pages 尚未由本任务启用。** 将来启用后，将以仓库根目录中的静态文件提供页面。在启用前，不要把任何预计的 Pages 域名当作正式地址或已上线地址。本任务不配置域名、不更改仓库可见性或远程设置。

## 反馈

隐私与支持反馈仅使用 [GitHub Issues](https://github.com/Chill-lucky/yinghuo-support/issues)。这是公开的 GitHub Issues，请勿在反馈中粘贴个人敏感资料，也请勿粘贴儿童的敏感资料。
